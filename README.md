# THE WORLD TODAY — Monday 23 November 2026

One image summing up 23 November's world news, for the make.fun
news-image-20261123 bounty.

**Heroes:** the AI rout hits Asia (Kospi −3.3% to 4,708.54), Guterres calls
for AI regulation before it's too late at the Bridgetown summit, and the US
lead over China falls to a record low (Asia Power Index gap 5.3).

**31 stories:** 3 hero scenes, 10 cards, 18 more in ALSO, plus a number
strip, a region bar, a world map with 13 numbered pins, and a DATE CHECK box
for stories that are NOT from 23 November.

## How it is built

- `draw.py` renders `entry.png` (1024×1024, PIL).
- `main.py` (stdlib only) validates the PNG and writes it to
  `MAKEFUN_OUTPUT_DIR/entry.png`.
